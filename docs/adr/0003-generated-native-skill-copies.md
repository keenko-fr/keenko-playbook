# ADR 0003: generated native skill copies

## Status

Accepted.

## Decision

The canonical installed skill copy lives under `.playbook/skills/`. The installer generates native copies under `.agents/skills/` and `.claude/skills/`.

Generated directories carry a marker and may be overwritten only when they were generated by Keenko Playbook. Existing human-owned skill directories are never silently replaced.

## Why

Native discovery is reliable across harnesses and platforms. Symlinks add portability problems; independently maintained copies drift.
