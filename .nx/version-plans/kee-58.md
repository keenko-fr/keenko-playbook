Provision hosted Context7 MCP at project scope for generated Codex and Claude Code harnesses. Fresh creation and the supported upgrade lifecycle through `bun x nx sync` add absent entries when safe, preserve equivalent and unrelated configuration, and reject customized conflicts before sync writes. Codex insertion preserves existing text exactly and fails with manual reconciliation instructions when a layout prevents a safe append; it never reserializes project-owned TOML. Generated guidance uses Context7 automatically for material library/API documentation questions while preserving local authority and harness trust/approval boundaries.

No new native migration factory is required: the existing registered Keenko sync generator owns these entries. Existing projects adopt them after installing the target release and running the documented Nx migration, install, sync, codegen, and check lifecycle. No credentials, Context7 application dependency, or floating subprocess are generated.
