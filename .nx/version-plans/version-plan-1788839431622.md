Establish Keenko 0.3.0 as the first supported native-Nx application baseline.

Fresh projects use the fixed Keenko Nx preset and native Nx lifecycle for creation, migrations, synchronization, and project code generation, with `bun run check` as the canonical merge-ready verification command.

Define Node 24 as the supported tooling runtime and Bun 1.4.x as the package manager, lockfile owner, and runtime where supported.

Configure native Nx Release with file-based version plans for future Keenko releases.

Published Keenko 0.2.x belongs to the superseded pre-native-Nx architecture and has no supported upgrade path to this baseline.
